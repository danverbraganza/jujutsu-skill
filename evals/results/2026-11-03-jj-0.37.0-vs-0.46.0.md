## What differed between the versions

- **Pushing a new bookmark.** On 0.37, the skill's push flow (`jj bookmark create X`, then
  `jj git push -b X`) failed in all 3 `push-new-bookmark` trials with
  `Refusing to create new remote bookmark search@origin`, plus jj's hint to run `jj bookmark track`.
  Agents tracked the bookmark and pushed again. jj 0.38 made `jj git push --bookmark` track a new
  bookmark itself, so on 0.46 the flow worked first time.
- **`--allow-new` is gone on 0.46.** In all 3 `push-undescribed-change` trials on 0.46, agents first ran
  `jj git push -b quick-fix --allow-new`. jj removed that flag in 0.42, so it was rejected, and agents
  retried without it. 0.37 still accepts it.

## Friction on both versions

None of these come from the version change:

- `discard-awkward-paths`: in 1 of 3 trials per version, the first `jj restore` failed, because
  `docs/notes (draft).md` is a fileset syntax error unless quoted.
- `revert-commit`: agents passed `-m` to `jj revert`, which takes no message flag, in 1 trial on 0.37
  and 2 on 0.46.
- `edit-earlier-commit`: in 2 of 3 trials per version, an agent ran `jj new` or `jj edit` on the empty
  working-copy commit that jj had already abandoned when the agent moved away from it.
